# Breast Cancer Patient Analysis Dashboard

## Project Overview
This project analyzes breast cancer patient data using Microsoft Power BI. It presents patient demographics, cancer stages, tumor size, and survival status through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Dashboard Pages
- **Page 1:** Patient Overview and Cancer Stage Analysis
- **Page 2:** Patient Demographics and Survival Analysis

## Key Skills Demonstrated
- Creating KPI cards
- Building interactive charts
- Data analysis and visualization
- Designing dashboards
